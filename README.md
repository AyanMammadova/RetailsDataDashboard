# Azərbaycan üzrə Pərakəndə Satışların Təhlili | Power BI

## Layihənin Məqsədi

Pərakəndə satış məlumatlarını təhlil etmək, məhsul kateqoriyaları və satış kanalları üzrə göstəriciləri müqayisə etmək, zaman ərzində baş verən dəyişiklikləri interaktiv qrafiklərlə izləmək.

## Hesabatın Məzmunu

- Ümumi satış və gəlir göstəricilərini əks etdirən kartlar.
- Məhsul kateqoriyaları üzrə satış, miqdar və gəlir göstəricilərini müqayisə edən cədvəl.
- Satış kanalları üzrə satılan məhsul miqdarını göstərən çubuq diaqramı.
- Ödəniş üsulları və müştəri seqmentləri üzrə sifariş sayını göstərən sütun diaqramı.
- Gəlirin zaman ərzində dəyişməsini göstərən xətti qrafik.
- İl və ay üzrə seçim etməyə imkan verən filtrlər.

## İstifadə Olunan Alətlər və Bacarıqlar

- Microsoft Power BI Desktop
- DAX ölçüləri
- Məlumatların vizuallaşdırılması
- İnteraktiv filtrləmə
- Pərakəndə satışların təhlili

## Layihə Faylları

- `azer-sales.pbix` — Power BI hesabatı və məlumat modeli.
- `images/dashboard.png` — hesabatın ekran görüntüsü.

## Hesabatı Necə Açmaq Olar?

1. Bu repozitoriyadan `azer-sales.pbix` faylını yükləyin.
2. Faylı Microsoft Power BI Desktop proqramında açın.
3. İl və ay filtrləri ilə istədiyiniz dövrü seçin.
4. Qrafiklərdəki elementlərə klikləyərək əlaqəli göstəriciləri araşdırın.

GitHub-da hesabatın ekran görüntüsünə baxmaq mümkündür. İnteraktiv imkanlardan istifadə etmək üçün `.pbix` faylını Power BI Desktop proqramında açın.
